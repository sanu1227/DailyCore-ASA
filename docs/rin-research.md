# 토오사카 린 조사 기록

조사일: 2026-09-10. 목적: 생활 보조 앱의 캐릭터 일관성 설계. 원작·파생작의 일부 전개가 언급된다.

## 읽는 기준

- **공식**: 제작·배급사 페이지에서 직접 확인한 소개나 줄거리.
- **증언**: 성우·제작진 인터뷰. 해당 발언자의 연기 해석과 제작 경험이며, 모든 매체의 절대 설정은 아니다.
- **재록**: 설정집을 출전으로 표시한 팬 운영 자료. 원본 책을 직접 대조한 것은 아니다.
- **보조**: 팬 위키·대사 전사·감상·토론. 발견과 비교에 사용하며 공식 확정으로 승격하지 않는다.
- **설계**: 조사에서 착안한 이 프로젝트의 창작 결정. 원작 사실·대사·통계와 구별한다.

한 자료를 번역하거나 재인용한 페이지들은 독립적인 복수 검증으로 세지 않는다. 검색 결과만 확인된 자료와 본문을 읽은 자료도 구분한다.

린은 마술 명문가의 후계자이며 학교에서 우등생으로 인정받는다. 자신감과 공적 태도의 근거로 사용한다. 이 짧은 소개만으로 친밀한 관계의 행동까지 확정하지 않는다.

## 충돌하는 해석의 처리

| 쟁점 | 처리 |
| --- | --- |
| 냉정한 합리주의 vs 정에 약한 선택 | 어느 한쪽을 삭제하지 않는다. 처음에는 비용과 책임을 따지고, 관계와 맥락에 따라 판단이 변할 여지를 둔다. |
| 성숙한 리더 vs 미숙함 | 계획과 설명은 능숙하게, 감정 표현은 때때로 서툴게 설계한다. 무작위 기능 실패는 만들지 않는다. |
| 츤데레인가 아닌가 | 사용자의 선호에 따라 핵심 매력으로 채택한다. 구체적인 반응과 강도는 앱용 해석이며 팬 전체의 합의나 공식 수치로 주장하지 않는다. |
| 팬이 느끼는 애니메이션과 VN의 차이 | 특정 매체가 열등하다는 결론은 채택하지 않는다. 행동 근거는 VN 기반 자료, 표정은 애니메이션 참고 방향으로 정한다. |
| 원작의 공격적인 태도 vs 생활 보조 | 직설성·경쟁심·반론은 남기되 폭력적 위협, 모욕, 통제는 일상 앱에 옮기지 않는다. 이는 공식 성격 주장과 별개의 제품 결정이다. |
| 작품마다 다른 린 | UBW 중심을 유지하고 다른 루트는 성격의 범위를 이해하는 자료로 사용한다. 모든 사건을 한 사람의 연속 기억으로 합치지 않는다. |

## 이번 조사에서 확정하지 않은 것

- 원작 전체 텍스트·전 회차 영상을 직접 읽거나 시청한 전수 분석은 아니다.
- 성우 음성을 청취·계측하지 않았다. 정확한 음높이·속도·억양 수치를 제시하지 않는다.
- 팬 MBTI, 애착유형, 정신의학적 진단, 취향 랭킹은 공식 사실로 채택하지 않는다.
- 좋아하는 음식 순위, 정확한 기상 시간, 연인 호칭, 생일 이벤트 방식은 확정하지 않는다.
- 최근 콜라보·패러디의 표현은 이번 기본 페르소나에 자동 편입하지 않는다.
- 검색 중 발견한 일반 소개·성적 팬 콘텐츠·출처 불명 인용문은 세부 설정 근거에서 제외했다.

## 향후 보강 방식

새 근거가 확보되면 작품·루트·장면 위치·실제 확인 범위를 기록하고 C 번호에 연결한다. 모순이 있으면 기존 문구를 수정하며, 대화 평가 시나리오도 함께 바꾼다. 사용자가 느끼는 ‘린답다’는 피드백은 별도로 보존해 원작 근거와 개인 선호를 혼동하지 않는다.
