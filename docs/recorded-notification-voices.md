# 백서아 알림음과 이전 녹음 보관

## 2026-10-18 현재 정책

백서아는 기존 일본어 캐릭터 녹음과 합성 대사를 재생하지 않습니다. 음량 설정을 따르는 짧은 차임만 사용합니다. 기존 파일과 아래 편집 기록은 원본 보존을 위해 남겨 두며, 아래의 녹음 재생 정책은 현재 앱에 적용되지 않습니다.

# 녹음 기반 린 알림음

## 2026-09-18 추가 변경

두 번째 제공 파일 `[티비플] 어리광 부리는 토오사카.mp3`에서 린의 반응 5개를 추가해 총 17개를 사용한다. 원본 대화 상대의 응답 구간은 제외했다. 새 구간도 로컬 재인식과 PCM 검사를 거쳤으며, 전사는 공식 자막이 아니다.

현재 재생 정책은 아래의 초기 상황별 배치를 대체한다. 모든 종류의 알림에서 전체 17개를 섞어 선택하며, 한 바퀴를 다 쓰기 전에는 같은 파일을 다시 선택하지 않는다. 한 바퀴가 끝날 때도 직전 파일은 피한다. 카테고리는 녹음 파일이 없을 때 차임 선택에만 사용한다.

설정의 **알림 음량**은 0~100%, 기본 70%다. **알림 설정 저장** 후 새로 생성하는 일반 카드·토스트·긴급 팝업·결산에 적용된다. 0%에서도 시각 알림은 표시한다. Windows나 다른 앱의 음량을 바꾸지 않고 재생할 WAV의 PCM 크기만 조절한다. **전체 알림 테스트**는 슬라이더의 현재 값으로 재생한다. 이미 대기열에 들어간 알림은 생성 시점의 음량을 사용한다.

아래는 첫 번째 녹음의 편집 및 초기 배치 기록이다.

사용자가 제공한 `붕괴 스타레일 토오사카 린 모든 음성(일본어) - Honkai Star Rail.mp3`에서 12개 구간을 추출했다. 원본은 수정하지 않았다. 로컬 faster-whisper로 일본어와 단어 경계를 분석하고, 추출 결과를 다시 인식해 대사 절단 여부를 점검했다. 사람이 직접 청음한 결과나 공식 자막으로 주장하지 않는다.

파일은 0.79~5.27초, 44.1 kHz 모노 PCM WAV다. 원래 속도·음높이를 유지하고 앞뒤 짧은 페이드, 저주파 정리, -20 LUFS 목표 음량과 -3 dB true-peak 제한을 적용했다. 무음·클리핑·재생 길이를 자동 검사한다.

| 알림 | 사용한 대사의 뜻 |
| --- | --- |
| 오전 브리핑 | 좋은 아침 |
| 일상 | 짧은 웃음 / 그렇지? / 별것 아니야 |
| 자리 비움 | 안심해 / 짧은 웃음 |
| 휴식·생활 체크 | 안심해 / 별것 아니야 |
| 식사 | 자, 봐 / 짧은 웃음 |
| 수업·공부·운동 | 함께 개척하자 / 우아하게, 화려하게, 대담하게 |
| 마감·게임 재촉 | 약속이야 / 자기 인생은 자기 손으로 개척해야지 |
| 취침 | 그럼, 내일 봐 |
| 집중 완료·결산 | 또 하나의 벽을 넘었어 / 함께 개척하자 |

알림 본문을 일본어로 읽는 기능은 아니며, 주제에 맞는 짧은 반응을 선택한다. 직접 대응하는 대사가 없는 식사·자리 비움에는 중립적인 반응을 배치했다. 오후 브리핑에 아침 인사가 나오지 않도록 시간대를 확인한다.

`public/assets/voices/recorded-manifest.json`에 원본 초 단위 구간·일본어 전사·한국어 뜻·알림별 목록이 있다. `app/notification-voice.cjs`에서 카테고리를 선택하고 `Play-RinSound.ps1`이 재생한다. 일반 카드, Windows 토스트, 긴급·결산 팝업 모두 같은 재생기를 사용한다. 최근 음성의 즉시 반복을 피하고, 프로세스 간 잠금으로 여러 음성이 동시에 재생되지 않게 한다. 녹음이 없으면 짧은 차임을 재생한다. 기존 합성 WAV는 보존하지만 이 경로에서는 사용하지 않는다.

편집 재현은 번들 Python으로 `desktop/prepare-recorded-voices.py <원본 경로> --edit --verify-speech`를 실행한다. 도구는 `.runtime/audio-tools`, 음성 인식 모델은 `.runtime/audio-models`에 있으며 앱 실행에는 필요 없다. 재편집 후 `node --test`, `node desktop/build.mjs --app-only`로 검사·배포한다. 실행 중인 린은 완전 종료 후 다시 실행해야 변경된 재생 연결을 사용한다.
