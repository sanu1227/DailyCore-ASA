# 백서아 이미지와 움직임

선택한 기존 5번 사진을 백서아의 기준 얼굴로 사용한다. 원본은 변경하지 않고 `public/assets/seoa/portrait.png`로 복사했다.

- 원본 SHA-256: `67d1a30d6459fffc5d9f5e404593d45fbba7d32fa59985b62fd4ba4c06064e6f`
- 이미지 생성 방식: 내장 `image_gen`의 원본 이미지 편집. 외부 API 키나 별도 유료 영상 서비스는 사용하지 않았다.
- `blink.png`: 눈꺼풀만 닫은 프레임. 같은 구도와 위치를 유지한다. UI에서는 두 눈 주변만 부드러운 마스크로 원본 위에 표시한다.
- `soft.png`: 입꼬리를 조금 올린 절제된 미소. 애교·과한 웃음 없이 같은 얼굴과 의상·조명을 유지한다.
- `thoughtful.png`: 입을 편하게 다문 차분하고 집중한 표정. 찡그림·노화·얼굴형 변경을 피한다.

얼굴 전체를 매 프레임 생성하는 영상 대신 원본과 눈 영역 프레임을 교체한다. 기본 사진의 얼굴을 그대로 보존하면서 깜박임을 표현하기 위한 선택이다. 다른 표정에서는 원본용 눈 프레임을 겹치지 않는다. 표정 편집은 생성 이미지이므로 원본과 픽셀 단위 일치를 보장하지 않는다.

움직임은 설정과 운영체제의 동작 줄이기를 따른다. 창을 숨기거나 다른 화면으로 이동하면 타이머를 중단하고 눈을 뜬 상태로 돌아간다. 이미지가 로드되지 않으면 기본 사진을 표시한다. 음성과 입 모양 동기화는 포함하지 않는다.

정확한 생성 프롬프트는 `public/assets/seoa/manifest.json`에 기록한다. 향후 의상이나 포즈를 추가할 때도 `portrait.png`를 원본으로 사용하고 얼굴형·이목구비·금발 단발을 고정한다.

## 2026-10-19 — 화면별 사진과 연속 프레임

- 50장 원본을 `public/assets/seoa/gallery/01.png`부터 `50.png`까지 복사했다. 사진별 생성 프롬프트는 `output/seoa-gallery/2026-10-18/manifest.json`에 보존한다.
- 일정, 루틴, PC 활동, 생활 기록, 하루 결산, 기억, 설정 화면에 장면 카드를 배치한다. 날짜가 같으면 같은 사진을 유지하고, '다른 사진'으로 해당 화면의 사진을 순환한다. 전체 화면의 풀을 합치면 50장을 모두 포함한다.
- Windows 알림은 공부·휴식·식사·성공 등 상황에 맞는 사진을 사용한다. 테마의 사진을 모두 사용한 뒤 다시 순환하며 직전 사진의 반복을 피한다.
- 대화 화면의 기본·일상·쉬는 시간은 각각 기준 얼굴, 29번 후디, 30번 휴식 사진이다. 선택은 이 PC의 브라우저 저장소에 보관한다. 홈 화면에는 휴식 모습을 사용한다.
- 내장 `image_gen`으로 실제 미세 움직임 프레임 9장을 추가했다. 기본 모습은 반쯤 감긴 눈·작은 시선 이동·고개 기울임, 일상과 휴식은 눈 감김·작은 시선 이동·고개 기울임을 사용한다. 기존 기본 모습의 눈 감김·미소·생각 프레임도 보존한다.
- 기본 사진을 3.6~5.4초 유지한 뒤 눈꺼풀, 눈 감김, 복귀, 시선 이동, 복귀, 고개 움직임, 복귀 순서로 표시한다. 시선과 고개 프레임은 140ms로 연결한다. 이는 작은 움직임의 프레임 애니메이션이며 실시간 영상·립싱크는 아니다.
- 각 장면의 자체 프레임만 사용한다. 기준 얼굴용 눈 마스크를 다른 옷·구도의 사진에 겹치지 않는다. 생성 프레임에는 미세한 픽셀 차이가 남을 수 있다.
- 움직임 OFF, OS 동작 줄이기, 창 숨김, 다른 화면으로 이동하면 타이머를 멈추고 기본 사진을 표시한다. 뒤로 가기 캐시에서 돌아오면 다시 시작한다. 누락된 프레임은 기본 사진으로 대체한다.
- 프레임과 정확한 프롬프트: `public/assets/seoa/motion/{studio,casual,rest}-manifest.json`.
