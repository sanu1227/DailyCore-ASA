# 린 일정 대화 안내

대화로 등록·수정·취소·복구할 수 있다. 변경 결과는 대화 아래 처리 카드에 표시한다. 날짜·시간·대상이 불명확하면 임의로 저장하지 않는다. 일정 언급만으로 날짜·시간을 반드시 되묻는 규칙은 없으며, 모든 대화 답변은 AI가 현재 문맥과 검증된 데이터를 바탕으로 작성한다.

수업·과제·게임·루틴·PC 사용 시간·생활 기록 조회와 일정 처리 결과에 고정 답변을 사용하지 않는다. 일정 변경 답변은 생성 후 실제 일정과 처리 카드가 함께 저장된 경우에만 전달한다. AI 생성이나 저장이 실패하면 변경을 반영하지 않고 오류를 표시한다.

질문 자체는 제한하지 않는다. AI가 대화에 맞춰 자연스럽게 질문할 수 있으며, 서버가 특정 질문이나 답변을 강제로 내보내지 않는다.

## 등록과 반복

| 할 일 | 예문 |
| --- | --- |
| 단일 일정 | 내일 오후 3시에 팀 회의 있어 |
| 매일 | 매일 오전 9시에 아침 회의 있어 |
| 매주 | 매주 월요일 오후 3시에 회의 있어 |
| 격주 | 격주 월요일 오후 3시에 회의 있어 |
| 매달 | 매달 15일 오후 4시에 회의 있어 |
| 종료일 포함 | 12월 말까지만 매주 월요일 오후 3시에 회의 있어 |
| 매일 종료일 포함 | 이번 달 말까지 매일 오전 9시에 회의 있어 |
| 격주 종료일 포함 | 올해까지만 격주 월요일 오후 3시에 회의 있어 |
| 매달 종료일 포함 | 내년 6월 30일까지 매달 15일 오후 4시에 회의 있어 |

- 격주는 처음 정한 날짜부터 14일 간격이다. 첫 회차와 다음 회차를 확인한다.
- 매달 29·30·31일이 없는 달에는 말일로 보정하고, 다음 달에는 원래 날짜로 돌아간다.
- 요일·매달 날짜·시각이 없거나 `3시`처럼 오전·오후가 모호하면 등록을 보류한다. 원하면 이어서 정보를 덧붙일 수 있으며, 확인 질문을 강제로 보내지는 않는다.

## 변경·취소·복구

| 할 일 | 예문 |
| --- | --- |
| 단일 일정 시간 변경 | 그 회의 오후 4시로 바뀌었어 |
| 반복 전체 시간 변경 | 그 회의 반복 전체 오후 4시로 바꿔줘 |
| 반복 주기 변경 | 그 회의 격주 화요일 오후 4시로 바꿔줘 |
| 매달 날짜 변경 | 그 회의 매달 20일로 바꿔줘 |
| 이번 회차만 변경 | 그 회의 이번 회차만 오후 4시로 바꿔줘 |
| 이번 주 회차만 변경 | 이번 주만 오후 4시로 바꿔줘 |
| 이번 주 회차만 취소 | 이번 주 회의만 취소해줘 |
| 다음 한 회차 취소 | 그 회의 이번 회차만 취소해줘 |
| 반복 전체 취소 | 그 회의 반복 전체 취소해줘 |
| 반복 전체 복구 | 그 회의 반복 전체 다시 잡혔어 |
| 직전 취소 회차 복구 | 그 회의 다시 잡혔어 |

- 범위 없는 반복 일정 변경은 `이번 회차` 또는 `전체`로 답한다.
- `그 회의`는 최근 처리 기록의 ID와 이름으로 찾는다. 여러 후보가 있으면 이름이나 `2번`처럼 번호를 말한다. 확인 도중 일정이 바뀌면 다시 요청한다.
- `이번 주`는 월~일이다. 매일 일정의 한 주 전체를 임의로 변경하지 않으며, 격주 일정에 회차가 없는 주는 다른 주를 바꾸지 않는다.
- 주기·요일·시간을 전체 변경하면 기존 회차별 예외를 해제한다. 제목·메모·종료일만 바꾸거나 전체 취소·복구하면 예외를 보존한다.

## 종료일 설정·연장·단축·해제·조회

| 할 일 | 예문 |
| --- | --- |
| 날짜로 설정 | 그 회의 종료일을 12월 31일로 바꿔줘 |
| 기간 연장 | 그 회의 내년 1월 말까지 연장해줘 |
| 기간 단축 | 그 회의 이번 달 말까지만 해줘 |
| 이번 주까지만 | 그 회의 이번 주까지만 해줘 |
| 종료일 해제 | 그 회의 종료일 없애줘 |
| 계속 반복 | 그 회의 계속 반복해줘 |
| 종료일 조회 | 그 회의 언제까지야? |
| 종료일 정보 보완 | 그 회의 종료일 바꿔줘 → 내년 1월 말 |
| 자동 종료된 일정 재개 | 회의 종료일을 내년 1월 말까지 연장해줘 |
| 취소·기간 만료 일정 복구 | 그 회의 반복 전체 다시 잡혔어 → 내년 1월 말까지 |

지원하는 종료 날짜 표현:

- `12월 말까지`, `11월 30일까지`, `2026년 12월 31일까지`, `2026-12-31까지`
- `이번 달 말까지`, `다음 달까지`, `다다음 달 15일까지`
- `올해까지만`, `내년 말까지`, `2028년 말까지`
- `이번 주까지만`, `다음 주 금요일까지`, `오늘까지`, `내일까지`, `모레까지`
- `종료일 없이`, `기한 없이`, `종료일 취소해줘`는 **종료일만 제거**한다. 일정 자체를 취소하지 않는다.

### 종료 정책

- 날짜는 PC의 현지 시간 기준이다. 마지막 날짜를 포함한다. `12월 말까지`는 12월 31일 당일까지이다.
- 연도가 없는 월·일은 오늘 이후 가장 가까운 해당 날짜로 해석한다. 과거 날짜를 정확한 연도로 지정하거나 존재하지 않는 날짜를 말하면 변경을 보류한다.
- 종료일과 첫 일정 날짜는 따로 해석한다. `12월 말까지 매주 월요일`은 첫 월요일을 12월 말로 옮기지 않는다.
- 남은 회차가 없으면 예정 목록·알림·AI의 앞으로 할 일정에서 제외한다. 앱을 꺼 둔 사이 종료일이 지나도 재실행 때 제외한다. 이미 전달한 알림은 회수하지 않는다.
- 기록은 `종료된 반복 일정`에 남는다. 종료일을 연장하거나 없애면 새로 복제하지 않고 원래 규칙과 ID로 재개한다.
- 종료일을 줄여 범위 밖이 된 회차 예외는 기록만 보존한다. 기간을 다시 늘리면 아직 미래인 예외도 다시 적용한다. 한 회차를 종료일 밖으로 옮기거나 복구하려면 먼저 기간을 늘려야 한다.
- UI 수정창은 반복 전체를 수정한다. 종료일을 비우면 기한 없이 반복한다.

## 안전 범위

`연장하지 마`, `취소하지 마`, `만약`, `연장할까?` 같은 부정·가정·질문만으로는 일정을 변경하지 않는다. 종료일 조회도 읽기 전용이다. 대화·처리 카드·일정 저장 중 하나라도 실패하면 변경 전체를 되돌린다.

모든 자연어를 무조건 해석하지는 않는다. 다음 조건은 현재 지원하지 않거나 정확한 날짜를 다시 말해야 한다.

- 여러 요일·여러 시각·여러 일정의 일괄 변경
- `세 번만`, `한 달 더` 같은 횟수 또는 상대 연장량
- `매년`, `매달 첫째 월요일`, `매달 말일`, 임의 간격의 반복
- `11월부터 12월까지` 같은 시작일과 종료일의 범위 문장

이 경우 한 번에 하나의 반복 규칙과 구체적인 종료 날짜를 말한다. 인식하지 못한 문장을 입력했을 때는 처리 카드가 실제로 생겼는지 확인한다.
