# DailyCore ASA

> 공개 소스 저장소입니다. 개인 데이터, 로그인 정보, 환경 설정, 로컬 실행 파일, 빌드 결과물과 실제 사용자 화면 캡처는 포함하지 않습니다. 원본 로컬 Git 이력을 가져오지 않은 현재 소스 스냅샷입니다.

BABYMONSTER 아사의 공개 사진을 사용하는 개인용 Windows 팬메이드 대화 앱입니다. 실제 아사 또는 소속사가 운영하는 공식 서비스가 아니며, 답변은 AI가 생성합니다. 연인 관계를 전제하지 않는 편안한 대화와 일정·생활 관리를 지원합니다. 자체 Electron 창에서 Codex만 사용합니다. Gemini·Qwen으로 자동 전환하지 않습니다.

## 사진과 움직임

- 공식 채널의 실제 공개 사진 4장을 대화·홈·일정·생활 기록·설정과 알림에 사용합니다. 상세 앱에서 사진을 선택하거나 `다른 사진`으로 바꿀 수 있습니다.
- 사진에 완만한 이동·확대 효과를 적용합니다. 원본 얼굴과 표정을 유지하며 눈 깜박임·립싱크·표정 프레임을 새로 생성하지 않습니다.
- 사진 움직임을 끄거나 운영체제의 동작 줄이기를 켜면 효과를 멈춥니다. 숨겨진 창에서도 움직임을 멈춥니다.
- 실행은 `Asa.cmd`를 사용합니다. 기존 `SeoA.cmd`, `Rin.cmd`와 내부 실행 파일·DB 이름은 호환성을 위해 유지합니다.
- 상세 앱의 기본 사진은 고해상도 `public/assets/asa/moon.jpg`이며, `MOON·CHOOM·SUPA DUPA LUV`를 선택할 수 있습니다. 공식 프로필 `portrait.jpg`는 작은 아이콘과 알림에 사용합니다. 파일 목록과 출처는 [아사 사진 기록](docs/asa-assets.md)에 정리합니다.
- 기존 대화 기록·일정·사용자 기억은 보존합니다. 전환할 때 기존 대화를 AI 문맥에서 제외하여 이전 캐릭터 설정이 이어지지 않게 합니다.
- 이전 캐릭터의 녹음은 재생하지 않습니다. 알림은 기존 음량 설정을 따르는 짧은 차임을 사용합니다.
- 일반 알림은 두 번째 모니터 오른쪽 아래의 차콜색 카드로 표시합니다. 마우스를 올리면 자동 닫힘을 멈추고, `열기`·`15분 뒤 다시`·`닫기`를 바로 사용할 수 있습니다. 재알림은 앱을 다시 켜도 유지합니다. 연속 카드는 2초 간격, 차임은 최대 1분에 한 번입니다.
- 생활 기록 알림은 기본으로 꺼져 있습니다. 기록 화면은 그대로 사용할 수 있으며, 원하면 설정의 `생활 기록 알림 받기 (선택)`을 켜세요. 끄면 미뤄 둔 생활 기록 알림도 다시 표시하지 않습니다.
- **생활** 화면에서 오늘 루틴 완료와 하루 기록을 함께 관리합니다. 등록한 루틴 관리는 접어서 표시하고, 최근 7일 기록과 평균은 아래에 모았습니다. 지난 기록을 눌러 수정하거나 `오늘`로 돌아올 수 있습니다. 기존 생활 기록 링크와 알림도 이 화면으로 연결됩니다.

## Windows 프로그램 실행

데스크톱 실행 파일은 저장소에 포함하지 않습니다. [소스 빌드 안내](docs/desktop.md)를 따라 생성한 `dist/RIN-win32-x64/RIN.exe`를 실행하세요. Chrome/Edge가 필요하지 않습니다. 기존 `Rin.cmd`도 빌드된 프로그램을 엽니다. 위젯의 X는 아사를 완전히 종료하며, 상세 앱의 X는 위젯으로 돌아갑니다. 앱 설정 또는 트레이의 **아사 종료**로도 종료할 수 있습니다.

기존 대화·일정 DB를 유지하며, 설치된 Codex CLI의 ChatGPT 로그인을 사용합니다. 실행에 필요한 Node와 Electron은 배포 폴더에 포함됩니다. 배포 폴더 전체를 함께 보관하세요. [빌드·데이터·e-Class 동기화 안내](docs/desktop.md).

개발 과정과 검증 기록은 [아사 개발노트](docs/development-log.md)에 시간순으로 정리합니다.

## 투명 위젯과 상세 앱

실행하면 두 번째 모니터(첫 비주 모니터)에 차콜색 반투명 대화 위젯이 열립니다. 처음 크기는 화면 비율에 맞추며 1920×1080 화면에서는 1056×594입니다. **오른쪽 아래 손잡이**를 끌거나 **⋯ 메뉴의 위젯 크기**에서 가로·세로 슬라이더를 움직여 크기를 바꿀 수 있습니다. 최소 480×360부터 현재 모니터의 작업 영역까지 조절하며, **기본 크기**로 처음 크기를 복원합니다. 손잡이에 키보드 포커스를 두고 방향키를 누르면 20px씩 바뀝니다. 패널·대화·입력창 폭은 창 크기에 맞춰 늘어나고, 입력창은 아래에 유지되며 긴 대화는 기록 영역에서 스크롤됩니다.

위젯은 직접 종료할 때까지 두 번째 모니터에 유지합니다. 일반 창처럼 다른 창 뒤로 가릴 수 있으며 항상 위에 고정하지 않습니다. 위쪽의 아사 이름 영역을 끌어 해당 화면 안에서 옮길 수 있습니다. 최소화와 고정 해제 버튼은 표시하지 않습니다. 기본 불투명도 64%의 둥근 패널 뒤로 바탕화면이 비치며, 패널 바깥 여백은 완전히 투명합니다. 본문은 20~22px이며 아사는 밝은 흰색, 사용자는 옅은 하늘색으로 구분합니다. 글씨 외곽선과 그림자는 없으며 입력창은 투명한 둥근 테두리입니다. **⋯ 메뉴의 배경 투명도**에서 0%(불투명)~100%(완전 투명)로 조절하면 배경만 즉시 바뀌고 설정이 자동 저장됩니다. **기본값**은 투명도 36%입니다.

대기 인사, 사진 위 장식 대사와 기본 추천 대화 버튼은 표시하지 않으며 답변 중에만 상태를 표시합니다. 직접 주고받은 대화 기록은 유지합니다.

패널 안팎의 빈 공간을 클릭하면 뒤의 바탕화면이나 창이 클릭됩니다. 입력창·버튼·이동 손잡이는 그대로 조작할 수 있고, 대화 글에서는 선택과 스크롤도 가능합니다. 확인 대화상자가 열리면 닫을 때까지 위젯에서 입력을 받습니다.

위젯의 **상세**를 누르면 1180×860의 전체 앱이 열립니다. 왼쪽 메뉴에서 대화·일정·루틴·활동·기록·기억·설정을 이용하며, 실제 사진과 완만한 사진 이동 효과를 표시합니다. **위젯으로**를 누르거나 상세 앱을 닫으면 대화 위젯으로 돌아갑니다. 두 창은 대화와 기록을 공유하고 입력 중인 초안은 각 창에 따로 보존합니다.

두 창의 위치·크기를 자동 저장합니다. 위젯은 다음 실행에도 두 번째 모니터 작업 영역 안에 복원하며, 모니터가 한 대면 해당 화면으로 옮깁니다. 두 번째 모니터를 다시 연결하면 위젯이 돌아갑니다. 상세 화면을 열거나 닫아도 위젯은 유지합니다. 위젯은 전용 손잡이와 메뉴로 크기를 조절하며, 상세 앱은 일반 창 가장자리 조절과 최대화도 지원합니다.

- `내일 오후 3시에 팀플 회의 있어`처럼 말하면 실제 날짜와 시간을 확인해 일정에 등록합니다.
- `금요일 치과 가야 해`라고 말하면 시간을 묻습니다. 이어서 `오후 3시`라고 답하면 같은 일정을 완성합니다.
- 오전·오후가 불분명하거나 날짜가 빠지면 되묻습니다. 날짜만 말한 과제 마감은 기존처럼 23:59로 저장합니다.
- 등록 결과는 대화 속 카드에 남고, `확인·수정`과 `등록 취소`를 사용할 수 있습니다. 같은 제목·과목·시각의 미완료 일정은 중복 저장하지 않습니다.
- 약속·회의 등 일반 일정은 시작 30분 안에 한 번 알립니다. 알림 설정과 방해 금지 시간을 따릅니다.

일정 추출과 사용자 기억 저장도 Codex를 사용합니다. 단순한 시간 보완은 모델 호출 없이 처리합니다. 추가 질문은 10분간 이어지며, 다른 주제로 넘어가거나 취소하면 등록 대기를 해제합니다. 여러 일정·복잡한 날짜 표현은 한 일정씩 나눠 말하고 등록 카드를 확인하세요.

## Codex로 실행하기

1. Codex 데스크톱 앱 또는 CLI를 설치하고 ChatGPT 계정으로 로그인합니다. 터미널에서는 `codex login`을 사용하고 `codex login status`로 확인할 수 있습니다.
2. `Asa.cmd` 또는 `dist/RIN-win32-x64/RIN.exe`를 실행합니다.
3. 위젯에서 대화합니다. 앱 대화 모델은 `gpt-6.1-sol`로 고정되며 실제 사용 모델은 앱 설정에 표시합니다. 개발용 Codex 프로젝트에서 선택한 모델과는 별개입니다.
4. 로그인 만료·사용량 부족·연결 오류가 발생하면 오류 원인을 표시합니다. 사용자가 로그인이나 결제를 처리한 뒤 다시 보낼 수 있습니다. 다른 제공자로 전환하거나 앱이 결제를 진행하지 않습니다.
5. 위젯의 X 또는 설정·트레이의 **아사 종료**로 종료합니다. 상세 앱의 X는 위젯으로 돌아갑니다.

ChatGPT 계정의 Codex 사용 한도를 공유하며 인터넷 연결이 필요합니다. Ollama와 OmniRoute를 자동 실행하지 않습니다. 기존 로컬 모델 파일과 수동 실행 스크립트는 보관하지만 앱 대화에 사용하지 않습니다. Codex 실행 파일을 자동으로 찾지 못하면 `RIN_CODEX_EXE`에 절대 경로를 지정할 수 있습니다.

Node.js 24 이상이 필요하며 실행용 Node와 Electron은 배포 폴더에 포함됩니다. 추가 npm 패키지는 없습니다. 검사: `node --test`.

## 현재 기능

- 친한 여사친처럼 시크한 한국어 반말 대화와 확인된 일정에 대한 가벼운 잔소리. 실제 인물의 사생활·감정·경험을 지어내거나 연인 관계를 전제하지 않습니다.
- 수업·과제·게임·루틴·PC 사용·생활 기록 조회와 일정 처리 결과도 AI가 답변합니다. 고정 대화 답변은 사용하지 않으며, 일정 변경은 답변 생성과 실제 저장이 모두 성공한 경우에만 결과를 보여줍니다.
- 대화 기록, 답변별 평가, 호칭·장난기 저장. ‘조금 어색해요’로 표시한 대화 한 쌍은 다음 AI 문맥에서 제외합니다.
- 대화에서 지속적인 취향·전공·생활 습관을 자동으로 추출해 기억합니다. 일반 대화에서는 추출과 답변 생성을 병렬로 진행하며, 명시적인 저장 요청은 추출 결과를 확인한 뒤 답합니다. 개인 사실이 없는 짧은 질문은 추출 호출을 생략합니다. 같은 내용은 중복 저장하지 않고 변경된 사실은 갱신합니다. 최대 30개·각 500자이며 기억 화면에서 직접 추가·수정·삭제할 수 있습니다. 일회성 일정은 기존 일정 기능으로 관리하고, 비밀번호·인증 정보와 기억하지 말라고 한 내용은 자동 저장하지 않습니다. 추출에 실패해도 대화는 계속되며, 답변 생성에 실패하면 기억도 저장하지 않습니다. 이전 대화 전체를 소급 분석하지는 않습니다.
- 요일·시간·강의실을 포함한 주간 수업 시간표 등록·수정·삭제.
- 과제·시험·기타 일정의 마감 관리와 완료 처리. 오늘 수업, 7일 안의 마감, 지난 마감을 자동 집계합니다.
- 수면·운동·식사·공부·기타 생활 루틴을 요일과 시각별로 등록하고 오늘 완료를 체크합니다. 미완료 루틴은 정한 시각과 30분 뒤에 알리고, 오늘 브리핑과 대화에도 반영합니다.
- 활성 프로그램의 실행 파일 이름과 사용 시간을 로컬에서 30초 간격으로 누적해 오늘의 전체·공부·게임·영상 사용 시간을 보여줍니다. 5분 이상 입력이 없으면 제외하며 기록은 90일 후 자동 삭제합니다.
- PC 활동 화면은 오늘 총사용 시간과 기록이 있는 분류만 표시합니다. 앱별 반복 막대는 없애고 사용 시간이 긴 앱 5개를 먼저 보여주며, 나머지는 펼쳐 확인합니다. 측정 상태와 설정을 요약 안에 모으고, 측정 기준·저장 범위는 하나의 접힌 안내로 정리했습니다. 측정을 꺼도 기존 기록을 볼 수 있습니다.
- 설정한 연속 사용 시간마다 휴식을 권하고, 취침 루틴 이후 게임 중이면 종료를 재촉합니다. 마감 하루 전 게임 경고에는 오늘 누적 게임 시간도 반영합니다.
- 수면 시간, 식사 횟수, 물, 운동 시간, 컨디션과 메모를 하루 한 번 기록하고 최근 7일 평균과 날짜별 기록을 확인합니다. 밤까지 기록하지 않으면 설정한 시각에 한 번 알려주며 대화에서 주간 생활을 물어볼 수 있습니다.
- 하루 결산은 완료한 루틴·일정과 기록된 PC 공부·개발·게임 시간만 보여줍니다. 오늘·내일의 가장 가까운 일정과 내일 수업을 함께 확인할 수 있습니다. 0개·0분 카드, 게임 시간 비교, 생활 기록 독촉과 자동 주간 요약은 표시하지 않습니다. 설정한 PC 사용 시간에 도달하면 하루 한 번 작은 알림 카드로 요약하며, 보여줄 내용이 없으면 건너뜁니다. 알림의 `결산 보기`는 앱의 결산 화면을 엽니다.
- Windows 트레이에서 아사 열기, 하루 결산·생활 기록 열기, 가장 급한 일정 확인, 25분 집중 시작, PC 활동 측정 일시 중지·재개, 전체 종료를 할 수 있습니다. 아이콘을 더블클릭하면 아사가 열립니다.
- 대화에서 일정 등록·수정·취소·완료 처리를 할 수 있습니다. `그 회의 오후 4시로 바뀌었어`, `팀플 회의 모레로 미뤄줘`, `그 회의 취소됐어`처럼 말하면 최근 대화의 일정 ID 또는 정확한 이름으로 처리합니다. 같은 이름이 여러 개거나 `4시`처럼 시각이 모호하면 임의로 변경하지 않습니다. 일정 언급만으로 날짜·시간·내용을 반드시 되묻는 규칙은 없습니다.
- 변경 결과와 이전 시각은 대화 카드에 남습니다. 대화로 취소한 일정은 알림에서 제외하고 `취소 되돌리기`로 복구할 수 있습니다. e-Class에서 가져온 일정을 직접 수정·취소하면 이후 동기화가 이를 덮어쓰지 않습니다. 학교 사이트 원본은 바뀌지 않습니다.
- `그 회의 다시 잡혔어` 또는 `팀플 회의 복구해 줘`로 취소한 일정을 대화에서 복구할 수 있습니다. 새 날짜·시간을 함께 말하면 반영하고, 기존 시간이 지났으면 새 시간이 정해질 때까지 복구를 보류합니다. 새 행을 추가하지 않고 원래 일정 ID·메모·연동 정보를 보존합니다. 대화 기록을 지웠어도 정확한 이름으로 취소 일정을 찾을 수 있습니다.
- `매일 오전 9시에 회의 있어`, `매주 월요일 오후 3시에 회의 있어`, `격주 월요일 오후 3시에 회의 있어`, `매달 15일 오후 4시에 회의 있어`로 반복 일정을 등록합니다. 원본 하나에서 다음 회차를 계산하며 회차별로 알립니다. 격주는 처음 안내한 날짜부터 14일 간격입니다. 매달 29~31일은 해당 날짜가 없는 달에 말일로 처리하고 다음 달에는 원래 날짜를 사용합니다.
- `그 회의 매일 오후 4시로 바꿔줘`, `그 회의 격주 화요일 오후 4시로 바꿔줘`, `그 회의 매달 20일로 바꿔줘`로 주기·요일·날짜·시간을 변경합니다. 정보나 변경 범위가 부족하면 처리를 보류합니다. `그 회의 취소됐어` 다음에 `전체`를 덧붙이면 반복 전체를 취소·복구합니다. 수정창에서도 반복 없음·매일·매주·격주·매달과 매달 날짜를 선택할 수 있습니다.
- `이번 주 회의만 취소해줘`, `이번 주만 오후 4시로 바꿔줘`로 한 회차만 변경합니다. 원래 반복 규칙은 유지하며, 취소한 회차의 알림은 건너뜁니다. `이번 주`는 월~일 기준이고, 이미 지난 회차를 다음 주로 바꿔 처리하지 않습니다. `이번 회차`는 다음 예정 회차를 가리키며, 변경한 회차를 대화에서 다시 지칭하면 같은 회차를 계속 수정합니다. `그 회의 다시 잡혔어`나 취소 카드의 되돌리기로 해당 회차만 복구할 수 있습니다.
- 모든 반복 주기에서 `이번 회차만` 수정·취소·복구할 수 있습니다. 매일 일정에 `이번 주만`이라고 하면 여러 회차를 임의로 변경하지 않고 한 회차를 선택하도록 안내합니다. 격주 일정은 회차가 없는 주를 건너뛴다는 안내만 하고 다른 주를 변경하지 않습니다.
- `12월 말까지만 매주 월요일 오후 3시에 회의 있어`처럼 반복 종료일도 정할 수 있습니다. 마지막 날짜를 포함하며, 이후 회차는 예정 목록·대화 문맥·알림에서 자동 제외합니다. 매일·격주·매달에도 같은 방식으로 적용합니다.
- `그 회의 내년 1월 말까지 연장해줘`, `그 회의 이번 달 말까지만 해줘`, `그 회의 종료일 없애줘`, `그 회의 언제까지야?`로 종료일을 변경·해제·조회합니다. 종료된 기록은 대학교 생활의 `종료된 반복 일정`에 보존하며, 기간을 연장하면 같은 ID로 다시 이어집니다. 수정창에도 종료일 입력을 추가했습니다.
- 반복 일정은 자동으로 다음 회차로 이어지며 일반 완료 버튼으로 반복 전체가 종료되지 않습니다. 즉시 멈추려면 전체 취소를 요청하세요. 수정창은 전체 적용이며, 반복 주기·요일·날짜·시간을 바꾸면 기존 회차별 예외를 해제합니다. 종료일만 바꾸면 예외를 보존하지만 종료일 밖 회차는 실행하지 않습니다. 회차별 이름 변경, 여러 요일·날짜·시간대, 횟수 제한, 매년 반복과 매달 첫째 월요일 같은 조건은 지원하지 않습니다. 매달 날짜는 1~31일 숫자로 지정합니다. 전체 예문과 안전 규칙은 [일정 대화 안내](docs/schedule-conversations.md)를 참고하세요.
- Chrome 확장 프로그램을 통한 한국공학대학교 e-Class Todo 수동 동기화. 같은 일정은 추가 생성하지 않고 변경 내용을 갱신하며, Todo에서 사라진 일정은 완료 확인 목록으로 옮깁니다.
- 수업 30분 전과 과제·시험·일정 3일 전·1일 전·3시간 전에 아사의 말투로 Windows 알림. 완료 일정 제외, 중복 방지, 방해 금지 시간 설정을 지원합니다.
- 마감이 24시간 안에 있을 때 현재 활성 창이 등록된 게임이면 가장 가까운 일정을 15·30·60분 간격으로 재촉합니다. 기본 간격은 15분이며 화면과 키 입력은 읽지 않습니다.
- 방해 금지 시간에는 일반 알림을 미루지만, 사용자가 실제로 게임 중이면 임박 마감과 취침 루틴 잔소리는 계속 표시합니다.
- 일반 알림과 하루 결산 카드는 비주 모니터 오른쪽 아래, 긴급 팝업은 중앙에 표시합니다. 모니터가 한 대면 해당 화면을 사용합니다.
- 알림 호스트 오류로 표시하지 못한 알림은 설정의 `놓친 알림`에 보관합니다.
- Codex 답변은 생성되는 대로 표시합니다. 완료되지 않은 답변은 저장하지 않고 초안을 유지합니다. 최종 답변과 기억은 생성 성공 후 함께 저장하며 기존 JSON API도 유지합니다.
- 설정에서 대화 응답·기억 추출·일정 해석별 실제 Codex 모델, 성공·실패와 첫 글자·전체 처리 시간을 확인합니다. AI를 호출하지 않은 일정 답변은 앱 규칙 처리로 표시합니다. 기억 추출이 늦게 끝나도 답변 모델 표시를 덮어쓰지 않습니다. 저장 실패는 모델 생성 결과와 별도 요청 오류로 표시합니다.
- Codex 연결과 로그인 상태를 5분마다 확인합니다. 연결 점검은 답변을 생성하지 않습니다.
- 설정에서 날짜별 자동 백업의 무결성을 확인하고 복원할 수 있습니다. 복원 전 현재 DB를 별도 안전 백업으로 보존합니다.
- 백엔드가 비정상 종료되면 최대 3회 자동 재시작합니다. 사용자가 `아사 종료`를 누른 경우에는 재시작하지 않습니다.
- 공식 채널에서 공개한 실제 사진을 알림과 대화에 사용합니다.
- 하루 첫 실행에는 e-Class 당일 동기화를 최대 5분 기다린 뒤 오늘 수업, 임박·지난 마감과 최우선 일정을 Windows 알림으로 브리핑합니다. 내용이 여러 개면 `1/전체 개수` 순서로 한 항목씩 표시하며, 마지막 브리핑은 대학교 화면에서도 다시 볼 수 있습니다.
- 마감 3시간 전과 게임 중 재촉은 항상 위에 뜨는 긴급 팝업으로 표시합니다. `지금 시작`은 25분 집중 타이머, `15분 뒤`는 해당 일정 미루기, `완료했어`는 완료 처리로 연결됩니다. 집중 중에는 학업 재촉을 멈추고 수업 알림은 유지합니다.
- 오류가 발생한 대화는 저장하지 않고 입력 초안을 유지합니다.
- 대화·기억 추출·일정 해석 모두 Codex 전용입니다. 인증·사용량·모델·응답 오류를 다른 제공자로 숨기지 않습니다.
- 평범한 잡담은 구체적인 의견·장난·짧은 배려로 이어갑니다. 불필요한 일정 데이터와 중복 지시를 줄이고, 문체 예시는 실제 사용자 사실과 구분합니다. 일반 대화는 한 번 생성하며 문체 때문에 자동으로 재생성하지 않습니다.

대화 음성 출력은 아직 없습니다. 움직임은 사진 전체에 적용하는 CSS 이동·확대 효과입니다. e-Class 일정이 Todo에서 사라져도 제출 완료로 단정하지 않고 사용자가 `완료 처리` 또는 `계속 관리`를 선택하게 합니다. 평가는 자동 재학습하지 않습니다. 빈 대화창에 기본 인사를 추가하지 않습니다.

## e-Class 연결하기

1. `Install-eClass-Sync.cmd`를 더블클릭합니다.
2. Chrome 확장 프로그램 화면에서 `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다`를 누르고 열린 `extensions/rin-eclass-sync` 폴더를 선택합니다.
4. 한국공학대학교 e-Class에 평소처럼 로그인합니다.
5. 아사의 `대학교 생활`에서 `e-Class 동기화`를 누릅니다. 확장 프로그램이 로그인된 e-Class 메인 화면의 Todo를 열어 과제·시험을 가져오며, 로그인이 필요하면 로그인 화면을 표시합니다.

확장 프로그램을 다시 로드한 경우에는 이미 열려 있던 아사 탭도 한 번 새로고침해야 새 연결 코드가 적용됩니다.

확장 프로그램은 `eclass.tukorea.ac.kr`의 현재 Todo 목록만 읽습니다. 아사는 비밀번호와 로그인 쿠키를 받거나 저장하지 않습니다. 확장 프로그램을 제거하면 연동은 중단되지만 이미 가져온 일정은 로컬 데이터에 남습니다. 마감 시각이 지난 일정은 대학교 생활의 `지난 과제` 칸으로 자동 이동합니다. 이전 동기화에는 있었지만 현재 Todo에서 사라진 일정은 `완료 확인 필요`에 표시되며, 제출했다면 `완료 처리`, 아직 해야 한다면 `계속 관리`를 선택할 수 있습니다.

### 매일 자동 동기화

앱 설정에서 **Windows 로그인 시 아사 시작하기**를 켜거나 `Enable-Daily-Startup.ps1`을 실행하면 Windows 로그인 때 두 번째 모니터에 위젯을 띄우고 트레이와 알림을 시작합니다. 상세 앱은 따로 열지 않으며 작업 중인 창의 포커스는 유지합니다. 사용자가 트레이 메뉴나 설정에서 **아사 종료**를 누르면 다음 로그인 또는 직접 실행 전까지 알림도 멈춥니다. e-Class 동기화가 필요할 때는 앱의 동기화 버튼을 사용합니다.

자동 실행을 해제하려면 `Disable-Daily-Startup.ps1`을 실행합니다. 비밀번호는 어느 경우에도 앱에 저장하지 않습니다.

## 데이터와 연결

- 대화·기억·설정·평가·시간표·학업 일정·생활 루틴·PC 활동·생활 기록과 e-Class 외부 일정 ID는 `data/rin.sqlite`에 저장됩니다. 파일은 암호화되지 않았으며 Git에서 제외됩니다.
- 앱을 시작할 때 기존 DB를 `data/backups/rin-YYYY-MM-DD.sqlite`에 하루 한 번 백업하고 최근 14일을 보관합니다.
- Codex 실행 파일과 로그인 정보는 Codex가 관리합니다. 앱 DB나 Git에 인증 정보를 복사하지 않습니다.
- 앱 서버는 `127.0.0.1:4317`에서만 실행합니다. Codex 자식 프로세스와는 표준 입출력으로 통신하며 별도 외부 포트를 열지 않습니다.
- AI 요청에는 캐릭터 프롬프트, 호칭·표현 강도, 현재 시각, 관련 기억·일정과 최근 대화가 OpenAI로 전송됩니다. 기존 ChatGPT·dots의 대화나 기억을 자동으로 가져오지 않습니다.
- PC 활동 측정을 켜면 활성 프로그램의 실행 파일 이름과 사용 시간, 자리 비움 여부만 확인합니다. 화면 내용·창 제목·주소·키 입력은 읽거나 저장하지 않습니다. 브라우저 안의 활동은 모두 기타로 분류합니다.
- 최근 최대 48메시지(24왕복)를 문맥으로 사용합니다. Codex 요청은 UTF-8 90KB 예산에 맞추어 오래된 대화 쌍부터 제외합니다. 기억과 새 메시지만으로도 한도를 넘으면 줄이도록 안내합니다. 성격 프롬프트는 자르지 않습니다. 이 범위를 넘는 대화를 무제한 기억하거나 자동 요약하지는 않습니다.
- 기억 추가·수정은 진행 중 대화를 보존하며, 현재 사용자의 정정과 최신 저장 사실을 과거 발언보다 우선합니다. 기억 삭제는 해당 사실이 옛 대화에서 되살아나지 않도록 기존 AI 문맥을 제외합니다. 화면 기록은 유지되며 ‘대화 비우기’로 삭제할 수 있습니다.
- 앱 대화·기억 추출·일정 해석에는 `gpt-6.1-sol`과 낮은 추론 강도를 요청합니다. 전역 Codex 설정이나 개발 대화의 모델을 변경하지 않습니다. 요청과 다른 모델이 반환되면 생성을 중단합니다. 로그인·모델 사용 권한과 실제 완료 여부를 확인하고, 기억 삭제·수정과 제외한 대화가 정확히 반영되도록 매 요청마다 앱이 최신 문맥을 전달합니다.
- 앱은 Host·Origin·요청 토큰·CSP 검사를 적용합니다. 같은 Windows 계정의 다른 프로그램과 데이터를 격리하는 보안 경계는 아닙니다. 외부 포트 공개용으로 설계하지 않았습니다.
