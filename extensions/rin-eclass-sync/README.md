# 아사 e-Class Sync 설치

이 확장 프로그램은 한국공학대학교 e-Class의 현재 Todo 목록을 읽어 `http://127.0.0.1:4317`의 아사 앱에 전달합니다. 비밀번호와 쿠키를 읽거나 저장하지 않습니다.

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위의 `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다`를 누릅니다.
4. 이 `rin-eclass-sync` 폴더를 선택합니다.
5. e-Class에 평소처럼 로그인해 둡니다.
6. 아사의 `대학교 생활` 화면에서 `e-Class 동기화`를 누릅니다. 확장 프로그램 팝업의 `과제·시험 가져오기` 버튼도 계속 사용할 수 있습니다.

권한은 `eclass.tukorea.ac.kr` 페이지에서 일정 목록을 읽고, 아사 로컬 페이지와 동기화 요청을 주고받는 데만 사용합니다.

기존 설치 업데이트: `chrome://extensions`에서 기존 `Rin e-Class Sync` 카드의 새로고침 버튼을 누르면 `아사 e-Class Sync` 0.3.2로 바뀝니다. 이미 열려 있던 e-Class 탭과 브라우저의 아사 탭도 새로고침합니다. 기존 폴더를 그대로 사용하며 다시 설치할 필요는 없습니다.
